#MiniRAG
This minimal implemantion of rag model
## Requirments 
-python 3.8 or later
### install python using miniconda 
 1) download and install miniconda from [here](https://continuumio-docs.readthedocs-hosted.com/miniconda/)
 2) create new env using :
```bash
 $ conda create -n mini-rag-app python=3.8

```
 3)activate conda :
```bash
$ conda  activate mini-rag-app
 ```
## instaltion 
### intall reqired packages
```bash
$ pip install requiremnts
```
### setup enviroment
```bash
$ cp .env.example .env
```
setup your enviroment like `open_ai_key`
